eBay API setup

To enable live posting to eBay, you need a free developer account. Here's how:

  1. Go to developer.ebay.com and create a free account
  2. Create an app to get your App ID, Dev ID, and Cert ID
  3. Get a User Token by going through eBay's OAuth flow
  4. Paste your token into the EBAY_TOKEN variable at the top of this file's script

The AI identification and listing generation features work without any API keys — only the posting step requires them.
